  1. ماینکرفت Bedrock را روی گوشی یا ویندوز باز کنید.

  3. تا پایین لیست بروید و روی Add Server بزنید.
  4. در Server Name بنویسید Snow Land
  5. در Server Address بنویسید 85.133.205.89
  6. در Port بنویسید 19132
  7. روی Save بزنید، بعد سرور Snow Land را از لیست انتخاب کنید و وارد شوید. 🎮
